# VaultSecret

- **node vault.ts --help**: use to see all command  
- **node vault.ts encrypt**: use for encrypt your secret key in .env file. This will keep your .env file to super secretly safe system.  
*(Remember! When you run this command. The system will ask you for a **password** to create the secret.vault file. Please keep it safely)*
- **node vault.ts decrypt**: use for decrypt your secret key in .env file. This will ask for a **password** to see your secret key
- **node vault.ts run -- < start_project >**: use for run the project when these files are using process.env inside of it.

Imperative File
-
- vault.ts
- secret.vault
